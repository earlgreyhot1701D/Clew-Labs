## The Clew Labs Story

### The Courtroom Came First. The Code Followed.

I spent over a decade inside California court and municipal operations (2015–present) before I began building software. In government and judicial systems, every action has statutory boundaries:
- Consequential claims must trace to primary evidence in the record.
- Rules and jurisdictional limits precede interpretation.
- When data is incomplete, the record declares the unknown rather than guessing.
- Human authority carries legal and constitutional consequence.

In early 2025, amidst an industry rush to sell generative AI to public agencies, I saw a recurring failure mode: vendors were wrapping non-deterministic language models around mission-critical workflows without boundary controls, audit logs, or evidentiary receipts.

Rather than critiquing AI from a distance, I decided to learn by doing. I began building working software in public to test high-stakes questions through falsifiable systems.

```
┌─────────────────────────────────────────────────────────────┐
│                    THE CLEW LABS ETHOS                      │
├─────────────────────────────────────────────────────────────┤
│ 1. Evidence Before Conclusion                               │
│    Consequential claims stay tethered to primary sources.   │
│    Retrieval and inference are never conflated.             │
│                                                             │
│ 2. Structure Before Intelligence                            │
│    Deterministic rules, access boundaries, and failure      │
│    modes belong in architecture before invoking a model.    │
│                                                             │
│ 3. Human Authority Remains Visible                          │
│    AI assists, triages, and explains. AI never quietly      │
│    acquires the power to decide.                            │
└─────────────────────────────────────────────────────────────┘
```

## Signature Systems Shipped

Every project at Clew Labs pairs **working code**, **live deployment**, and a **first-person technical field note**:

### 🏛️ [Verity Lex](https://verity-lex.vercel.app) · *Readiness Intelligence for Superior Courts*
A cited public record readiness surface for California courts. A bounded agent locates and extracts evidence; a deterministic scoring registry computes the result. Every claim traces to an immutable audit bundle with declared unknowns.
* **Stack:** Next.js · GPT 5.6 · Tavily · Deterministic TypeScript Engine · Published Scoring Registry
* **Source:** [`github.com/earlgreyhot1701D/verity-lex`](https://github.com/earlgreyhot1701D/verity-lex)
* **Companion Field Note:** [“Open AI Build Week: Foundation First, Software Second”](https://dev.to/earlgreyhot1701d/open-ai-build-week-3fi8)

### 🤖 [Agentis Lux](https://agentislux.io) · *The Second Audience Scanner & Benchmark*
A developer scanner and 50-site empirical benchmark showing what autonomous retrieval agents experience when reading websites: latency traps, hidden permissions, and structural barriers.
* **Stack:** AWS Lambda · Amazon Bedrock · DynamoDB · Vercel · Deterministic Parser Suite
* **Source:** [`github.com/earlgreyhot1701D/perseus-clew`](https://github.com/earlgreyhot1701D/perseus-clew)
* **Companion Field Note:** [“I built it twice. Didn't place twice. Then Google and Vercel shipped it.”](https://dev.to/earlgreyhot1701d/i-built-it-twice-didnt-place-twice-then-google-and-vercel-shipped-it-ldd)

### 🛡️ [Heimdall](https://github.com/earlgreyhot1701D/heimdall) · *AI Gateway RBAC Least-Privilege Harness*
A reproducible least-privilege test harness of RBAC at an AI gateway (Bifrost). Three scoped roles evaluated across three model tiers, nine calls, a negative control, and a falsification test tracing to an append-only audit log.
* **Stack:** Bifrost Gateway · Python Test Suite · Least-Privilege Policy Controls · Append-Only Receipts
* **Source:** [`github.com/earlgreyhot1701D/heimdall`](https://github.com/earlgreyhot1701D/heimdall)
* **Companion Field Note:** [“Scoping Permissions with RBAC at the AI Gateway”](https://dev.to/earlgreyhot1701d/gating-access-with-bifrost-nine-calls-three-refusals-one-trap-46h4) *(Sponsored Evaluation)*

### 🧭 [Clew Directive](https://clewdirective.com) · *Multi-Agent Learning Navigator*
A stateless, privacy-focused curriculum synthesizer providing personalized learning paths through verified free resources. Multi-agent Scout + Navigator + Curator pattern on AWS with zero retained data.
* **Stack:** AWS Amplify · Amazon Nova · AWS Lambda · S3 · TypeScript CDK · Next.js
* **Source:** [`github.com/earlgreyhot1701D/Clew-Directive`](https://github.com/earlgreyhot1701D/Clew-Directive)
* **Recognition:** AWS 10,000 AIdeas Semifinalist
* **Companion Field Note:** [“AIdeas: Clew Directive — Free AI Learning Navigator”](https://builder.aws.com/content/39mEGMF2RFcE1Yt3xZ97TKFz4Xs/aideas-clew-directive-free-ai-learning-navigator-or-stop-following-the-hype-start-directing-the-search)

### ⚖️ [Themis Lex](https://themislex.org) · *Role-Based Judicial AI Alignment*
Role-based AI readiness self-check for California judicial staff. Evaluates specific court workflows against sensitivity guidelines to determine where AI can safely assist and where human authority must remain.
* **Stack:** Claude Haiku · AWS Bedrock · AWS Amplify · Server-side PDF engine

## Portfolio Architecture

This repository hosts the public web home of Clew Labs:

* **Pure Vanilla Architecture:** Single-file HTML5, CSS3 tokens, and lightweight vanilla JS. Zero runtime dependencies, no build steps, instant page load.
* **Executive One-Sheet ([`resume.html`](https://earlgreyhot1701d.github.io/Clew-Labs/resume.html)):** On-brand single-page executive brief with calibrated `@media print` rules for clean 1-page PDF export.
* **AI & Search Discoverability:**
  * [`llms.txt`](https://earlgreyhot1701d.github.io/Clew-Labs/llms.txt) — Token-efficient context for frontier LLM answer engines (Perplexity, ChatGPT, Claude).
  * [`robots.txt`](https://earlgreyhot1701d.github.io/Clew-Labs/robots.txt) — Explicit policy welcoming AI research crawlers while disallowing scrapers.
  * [`sitemap.xml`](https://earlgreyhot1701d.github.io/Clew-Labs/sitemap.xml) — Validated search index.
  * Schema.org JSON-LD — Semantic knowledge graph registering `Person`, `Organization`, and `SoftwareApplication` entities.
